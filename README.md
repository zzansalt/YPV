# YouTube Precise Volume

유튜브 플레이어에서 슬라이더뿐 아니라 숫자를 입력해 볼륨을 정확하게 조절할 수 있는 Chrome 확장 프로그램입니다.

## 기능

- 유튜브 기본 볼륨 컨트롤 옆에서 0–100% 값을 직접 입력
- 확장 프로그램 팝업에서 볼륨 올리기·내리기 단축키 설정

## 설치

### 방법 1
1. 이 저장소를 내려받거나 복제합니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 선택하고 프로젝트 폴더를 지정합니다.

### 방법 2
1. [다운로드](https://github.com/zzansalt/YPV/releases)에서 최신 파일을 다운 받습니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 파일을 드래그 앤 드롭 합니다.

## 사용법

유튜브 플레이어의 볼륨 아이콘에 마우스를 올리면 숫자 입력란이 표시됩니다. 0에서 100 사이의 값을 입력하면 적용됩니다.

확장 프로그램 아이콘을 누르면 팝업이 열립니다. 볼륨 올리기와 내리기를 각각 선택한 뒤 원하는 키 또는 키 조합을 누르고, 한 번 입력할 때 바꿀 볼륨 폭을 지정하세요. 유튜브 페이지가 활성화되어 있을 때 단축키가 작동합니다.

## 권한 및 개인정보

- `storage`: 팝업에서 지정한 단축키와 변경 폭을 Chrome 동기화 저장소에 저장합니다.
- 사이트 접근: 유튜브 페이지 안에 숫자 컨트롤을 표시하고 플레이어 볼륨을 조절하기 위해 `youtube.com`에서만 실행됩니다.
- 시청 기록이나 개인 정보를 수집하거나 외부 서버로 전송하지 않습니다.
